Deploying to Vercel (.vercel.app)

Follow these simple steps to host this web app on your custom Vercel domain.

1 Push to GitHub

Upload index.html and vercel.json to a new GitHub repository.

2 Import on Vercel

Log into Vercel.com, click Add New Project, and select your GitHub repository.

3 Instant Deploy

Vercel automatically detects the static setup via vercel.json and publishes your app to *.vercel.app.
